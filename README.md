# 쑥쑥뽑아

쑥쑥뽑아는 교실에서 학생 번호를 빠르게 무작위로 뽑기 위한 브라우저 기반 번호 추첨 도구입니다.

별도의 서버, 프레임워크, 빌드 도구 없이 `index.html`을 브라우저에서 바로 열어 사용할 수 있도록 만든 작은 JavaScript 앱입니다. 교사는 전체 인원과 제외할 번호를 설정하고, 화면의 큰 공을 돌려가며 학생 번호를 하나씩 뽑을 수 있습니다.

---

## 이 저장소에 대하여

이 저장소는 쑥쑥뽑아의 정적 웹앱 버전입니다.

- 저장소: <https://github.com/ShinJaehun/suksuk_picker>
- 실행 방식: 브라우저에서 `index.html` 직접 열기
- 주요 파일: HTML, CSS, JavaScript ES modules
- 서버 필요 없음
- 빌드 과정 필요 없음

쑥쑥뽑아는 수업 중 다음과 같은 상황에서 사용할 수 있습니다.

- 발표할 학생 뽑기
- 문제를 풀 학생 뽑기
- 모둠 활동 순서 정하기
- 게임이나 활동에서 참여자 순서 정하기
- 이미 뽑힌 학생을 제외하고 계속 뽑기
- 특정 번호를 제외하고 무작위 추첨하기

---

## 왜 만들었나

교실에서는 “누가 발표할까?”, “이번에는 누가 문제를 풀어볼까?”, “다음 차례는 누구로 할까?” 같은 상황이 자주 생깁니다.

이때 교사가 직접 번호를 부르면 특정 학생에게 편중될 수 있고, 아이들이 보기에 공정하지 않다고 느낄 수도 있습니다. 반대로 단순 랜덤 도구를 쓰면 이미 발표한 학생이 다시 뽑히거나, 오늘 결석한 학생 번호가 뽑히는 불편함이 생깁니다.

쑥쑥뽑아는 이런 교실 상황을 고려해 다음을 목표로 만들었습니다.

- 학생들이 볼 수 있는 큰 번호 표시
- 뽑힌 번호 목록 유지
- 이미 뽑힌 번호는 다시 뽑지 않기
- 제외할 번호 설정
- 잘못 뽑은 번호를 다시 후보로 되돌리기
- 브라우저만 있으면 바로 실행
- 수업 중 끊김 없이 단순하게 사용

---

## 주요 기능

### 1. 번호 무작위 추첨

`시작` 버튼을 누르면 번호가 빠르게 바뀌며 추첨이 시작됩니다.

다시 버튼을 누르면 현재 표시된 번호가 확정되고, 해당 번호는 뽑힌 번호 목록으로 이동합니다. 이후 남은 번호 중에서만 다시 추첨합니다.

기본 버튼 흐름은 다음과 같습니다.

| 상태 | 버튼 표시 |
| --- | --- |
| 시작 전 | 시작 |
| 추첨 중 | 뽑아 |
| 번호 확정 | 쑥쑥 |
| 모두 뽑은 뒤 | 다시 |

---

### 2. 인원 설정

설정 창에서 전체 인원을 입력할 수 있습니다.

예를 들어 인원을 `25`로 설정하면 1번부터 25번까지가 추첨 후보가 됩니다.

설정값은 브라우저의 `localStorage`에 저장되므로, 같은 브라우저에서 다시 열었을 때 이전 설정을 이어서 사용할 수 있습니다.

---

### 3. 제외 번호 설정

설정 창에서 제외할 번호를 입력할 수 있습니다.

예를 들어 결석한 학생이나 오늘 추첨에서 제외할 학생이 있다면 해당 번호를 제외할 수 있습니다.

제외 번호는 쉼표로 구분해 입력하는 방식입니다.

```text
3, 7, 12
```

제외된 번호는 추첨 후보에 들어가지 않습니다.

---

### 4. 뽑힌 번호 목록

번호를 하나씩 뽑으면 아래쪽에 뽑힌 번호가 작은 공 형태로 표시됩니다.

뽑힌 번호 목록은 단순 기록이 아니라 현재 추첨 상태의 일부입니다. 이미 뽑힌 번호는 남은 후보에서 빠지기 때문에 다시 뽑히지 않습니다.

---

### 5. 뽑힌 번호 되돌리기

뽑힌 번호 목록에서 특정 번호 공을 클릭하면 그 번호를 다시 후보 목록으로 되돌릴 수 있습니다.

수업 중 실수로 번호를 확정했거나, 학생이 자리를 비웠다가 돌아온 경우에 사용할 수 있습니다.

---

### 6. 마지막 번호 처리

남은 번호가 하나뿐일 때는 별도의 랜덤 회전을 오래 유지하지 않고, 마지막 번호를 확정하고 `다시` 상태로 넘어갈 수 있도록 처리합니다.

모든 번호를 다 뽑은 뒤에는 `다시` 버튼으로 현재 설정을 기준으로 추첨을 새로 시작할 수 있습니다.

---

### 7. 진행 상태 저장

쑥쑥뽑아는 현재 진행 중인 추첨 상태를 `localStorage`에 저장합니다.

저장되는 정보는 다음과 같습니다.

- 현재 표시 중인 번호
- 남은 번호 목록
- 이미 뽑힌 번호 목록
- 다음 예약 번호
- 설정값

따라서 페이지를 새로고침해도 가능한 경우 이전 추첨 상태를 복원합니다.

---

### 8. 관리 페이지와 다음 번호 예약

`control.html`은 진행 제어를 위한 관리 페이지입니다.

관리 페이지에서는 다음에 뽑힐 번호를 미리 예약할 수 있습니다.

예를 들어 다음 차례를 반드시 특정 학생으로 지정해야 하는 수업 상황이 있을 때, 관리 페이지에서 번호를 예약하면 다음 확정 시 그 번호가 먼저 선택됩니다.

관리 페이지의 주요 기능은 다음과 같습니다.

- 다음 1명 예약
- 예약 취소
- 현재 예약 번호 표시
- 예약 결과 메시지 표시

예약 번호는 다음 조건을 만족해야 합니다.

- 숫자여야 합니다.
- 전체 인원 범위 안에 있어야 합니다.
- 제외 번호가 아니어야 합니다.
- 이미 뽑힌 번호가 아니어야 합니다.
- 아직 남아 있는 번호여야 합니다.

---

### 9. 여러 화면 동기화

쑥쑥뽑아는 `localStorage`와 `storage` 이벤트를 이용해 설정과 진행 상태를 동기화합니다.

같은 브라우저에서 표시용 화면과 관리용 화면을 함께 열어 두면, 설정이나 진행 상태가 변경될 때 화면을 다시 초기화하고 최신 상태를 반영할 수 있습니다.

## 사용 방법

### 1. 기본 추첨 화면 열기

브라우저에서 다음 파일을 엽니다.

```text
index.html
```

또는 정적 파일을 웹 서버에 올린 경우 해당 주소로 접속합니다.

---

### 2. 설정하기

화면의 `설정` 버튼을 누릅니다.

설정 창에서 다음 값을 입력합니다.

- 이름
- 인원
- 제외할 번호

입력 후 `적용`을 누르면 설정이 저장되고 추첨 후보가 다시 만들어집니다.

---

### 3. 번호 뽑기

`시작` 버튼을 누르면 번호가 빠르게 바뀝니다.

추첨 중 다시 버튼을 누르면 현재 번호가 확정됩니다. 확정된 번호는 아래쪽 뽑힌 번호 목록으로 이동합니다.

---

### 4. 번호 되돌리기

아래쪽 뽑힌 번호 목록에서 작은 번호 공을 클릭하면 해당 번호가 다시 후보로 돌아갑니다.

---

### 5. 관리 페이지 사용하기

필요하면 별도 탭에서 다음 파일을 엽니다.

```text
control.html
```

관리 페이지에서 다음 번호를 예약하거나 예약을 취소할 수 있습니다.

## 최근 리팩토링 방향

초기 버전의 쑥쑥뽑아는 상대적으로 단순한 JavaScript 파일 중심 구조였습니다.

현재 버전은 앱이 작다는 장점을 유지하면서도, 유지보수하기 쉽도록 ES modules 기반으로 역할을 나누었습니다.

### 1. 앱 진입점 분리

`js/app.js`는 앱의 시작점입니다.

여기에서 상태, DOM 요소, 저장소, 게임 초기화, 추첨, 예약, 설정 폼, 모달, 이벤트 바인딩을 연결합니다.

---

### 2. 상태를 중심에 둔 구조

DOM 텍스트나 화면 모양을 보고 현재 상태를 추론하지 않고, 앱 상태 객체를 중심으로 동작하도록 정리했습니다.

대표적인 상태는 다음과 같습니다.

- 설정 상태
- 현재 추첨 세션
- 남은 번호 목록
- 뽑힌 번호 목록
- 현재 표시 번호
- 다음 예약 번호
- UI 관련 값

---

### 3. 추첨 로직 분리

`js/game/picking.js`는 번호 추첨 흐름을 담당합니다.

주요 역할은 다음과 같습니다.

- 추첨 시작
- 추첨 중지
- 번호 확정
- 마지막 번호 처리
- 모든 번호를 뽑은 뒤 다시 시작
- 뽑힌 번호를 후보로 되돌리기
- 효과음 재생

---

### 4. 초기화 로직 분리

`js/game/initGame.js`는 설정을 읽고, 번호 후보를 만들고, 저장된 세션을 복원하는 역할을 담당합니다.

특히 저장된 세션이 현재 설정과 맞는지 검증한 뒤 복원하도록 구성되어 있습니다.

---

### 5. 예약 번호 흐름 분리

`js/game/reservation.js`는 다음 번호 예약 기능을 담당합니다.

예약 번호는 남은 번호 목록 안에서만 허용되며, 제외 번호나 이미 뽑힌 번호는 예약할 수 없습니다.

---

### 6. 저장소 접근 분리

설정 저장과 세션 저장은 각각 별도 모듈로 분리되어 있습니다.

- `js/storage/settingsStorage.js`
- `js/storage/sessionStorage.js`

이를 통해 `localStorage` 접근이 여러 파일에 흩어지지 않도록 했습니다.

---

### 7. 렌더링 분리

`js/ui/render.js`는 현재 상태를 화면에 반영하는 역할을 담당합니다.

현재 번호 표시, 뽑힌 번호 목록 표시, 예약 상태 표시처럼 화면에 쓰는 작업을 이 파일에 모았습니다.

## 설계 원칙

### 브라우저에서 바로 실행한다

쑥쑥뽑아는 작은 교실 도구입니다. 설치나 빌드 과정 없이 `index.html`을 바로 열어 사용할 수 있어야 합니다.

### 상태를 명확하게 관리한다

화면에 적힌 글자나 DOM 구조를 현재 상태의 기준으로 삼지 않고, 상태 객체를 기준으로 화면을 다시 그리는 방향을 지향합니다.

### 부작용은 가장자리로 모은다

DOM 변경, `localStorage`, 타이머, 효과음 재생 같은 부작용은 가능한 한 모듈의 가장자리에서 다루도록 정리했습니다.

### 큰 프레임워크를 도입하지 않는다

앱의 규모가 작기 때문에 React, Vue, Rails 같은 프레임워크를 도입하지 않습니다. 단순한 HTML/CSS/JavaScript 구조를 유지합니다.

### 수업 중 동작 안정성을 우선한다

추첨 중 타이머, 마지막 번호 처리, 설정 변경, 새로고침, 되돌리기 같은 흐름이 수업 중 끊기지 않도록 하는 것을 우선합니다.

## 수동 점검 항목

의미 있는 변경 후에는 브라우저에서 다음 흐름을 확인하는 것이 좋습니다.

1. 빈 `localStorage` 상태에서 처음 열기
2. 설정 창 열기, 닫기, 적용하기
3. 인원 수 변경 후 번호 후보 확인
4. 제외 번호가 추첨에서 빠지는지 확인
5. `시작` → `뽑아` → 번호 확정 흐름 확인
6. 마지막 번호 처리 확인
7. 모든 번호를 뽑은 뒤 `다시` 동작 확인
8. 뽑힌 번호 공을 클릭했을 때 후보로 되돌아가는지 확인
9. 새로고침 후 진행 상태가 복원되는지 확인
10. `control.html`에서 다음 번호 예약과 예약 취소 확인
